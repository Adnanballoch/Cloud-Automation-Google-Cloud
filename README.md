**Category:** Enterprise AI Automation
**Part of:** AutoMatrixLab

## Overview

Build and run a business on Google Cloud, from the first command to the full deployment. I built this platform so anyone can learn, develop and build real work on Google Cloud (GCP) for free, against Google Cloud emulators on their own computer. It never connects to a real Google Cloud account.

## What it does

Learn (live): cloud skills organised by the Google Cloud certification exam areas, with hands-on tasks for Cloud Storage, Firestore, Datastore and Pub/Sub on Google's local emulators, and the other services explained with decision questions.

Learn also covers FinOps and use cases.

## What it works on

Use (live): real commands and Google Cloud's Python client libraries against Google Cloud emulators on your own PC, free, with a live view of the resources and Check my result.

## What you get

Build (in development): the same industry deployments as the AWS platform, built for Google Cloud.

Guided tours, a narrated demo and the AI assistant. The AI assistant runs on the platform itself and keeps your keys on your own machine, which is part of why nothing here touches a real cloud account.

## Tech Stack

Real commands and Google Cloud's Python client libraries, against Google's local emulators on your own PC.

Google Cloud emulators, Python client libraries, Cloud Storage, Firestore, Datastore, Pub/Sub

## Features

- Free, with no Google Cloud account.
- Cloud skills organised by the Google Cloud certification exam areas.
- Hands-on tasks for Cloud Storage, Firestore, Datastore and Pub/Sub.
- A live view of the resources, and Check my result.
- FinOps and use cases.
- Guided tours and the AI assistant.
- Never touches a real cloud account.
